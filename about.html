AG About

Ahmed Aly Ghaly.

Web Developer & UI/UX Designer — Ajman, UAE

I'm a Web Developer & UI/UX Designer based in Ajman, UAE. I design the experience, then build it myself — Figma to WordPress, Elementor Pro, or React — so nothing gets lost in a hand-off between designer and developer.

My process stays the same across projects: understand what the product needs to do, design the system that does it, build it so it holds up on a real phone on a real connection, then refine it against what people actually do once it's live.

01 Systems thinking

Outside client work, same habit of mind.

Chess, football, backgammon — things where position matters more than raw force, and where the current move is never really the point.

01

Chess

Every move is a trade-off made now for a position two or three moves out. It's the same discipline a checkout flow needs — you're rarely solving today's problem in isolation.

02

Football

A team only works when eleven separate jobs are reading the same system in real time. That's organization design, same as any product with more than one contributor.

03

Backgammon

Dice add luck, but the board still rewards whoever reads the probabilities correctly over a long run. Software has its own version of noisy input and disciplined response.
